# qr-code-generator
My first python Project - QR Code Generator

## Features

- Generates a QR code
- Asks the user for a website address.
- Checks if the input is empty.
- Saves the QR code as a PNG file.

## Requirements

- Python
- qrcode library

## Installation

```bash
python -m pip install "qrcode[pil]"
```

## How to Run

```bash
python main.py
```
